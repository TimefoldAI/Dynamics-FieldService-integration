# Security policy

Please do not report a security problem in a public issue.

Report it privately through
[GitHub private vulnerability reporting](https://github.com/TimefoldAI/Dynamics-FieldService-integration/security/advisories/new).
Tell us which class, script, or solution component is affected, and how to reproduce the problem.
Please leave out your API key, your tenant ID, your Dynamics environment details, and any customer data.

For a security problem in the Timefold platform or the Timefold models, contact Timefold support.
